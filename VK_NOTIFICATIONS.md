# Уведомления Vorby в ВКонтакте

На сайте: **Настройки → ВКонтакте · мой личный бот**. Поддержка включена в код, но доставка по умолчанию выключена. Нужны твоя частная группа и её ключ; без них реальные сообщения не отправляются.

Бот предназначен для одного человека: все сообщения отправляются только личному ID из локального `.env`. Подписок для других пользователей и публикаций на стене нет. Через сайт изменить получателя или добавить новых нельзя. Приватность самой группы нужно установить в ВК - программа не создаёт группу и не меняет её настройки.

## Подключение

1. В ВК открой **Сообщества → Создать сообщество**. Создай именно **группу**, назови её «Vorby Pro». В **Управление → Настройки → Тип группы** выбери **Частная** и сохрани. Не приглашай участников и не назначай других администраторов. Если используешь существующую группу, проверь эти настройки и её участников самостоятельно.
2. В управлении сообществом включи **Сообщения сообщества**. В настройках бота включи **Возможности ботов**, если этот пункт присутствует.
3. Найди **Работа с API → Ключи доступа → Создать ключ**. Требуется ключ **сообщества** с правом **Сообщения**. Дополнительные права управления аккаунтом не нужны. Если ВК просит подтверждение, выполни его самостоятельно.
4. В локальном `.env` рядом с `manage.py` добавь:

   ```dotenv
   VK_COMMUNITY_TOKEN=твой_ключ_сообщества
   VK_USER_ID=числовой_ID_твоей_личной_страницы
   ```

   Используй настоящее число, а не короткое имя страницы, ID сообщества или беседы. Например, для адреса `vk.com/id123456` число — `123456`. Для страницы с коротким именем найди числовой идентификатор в настройках личного VK ID. При использовании `INVEST_ENV_FILE` редактируй указанный там файл. Секреты не отправляй в чат и не сохраняй в Git. `.env.example` содержит только пустые поля.
5. Со своей личной страницы открой диалог с сообществом, разреши сообщения от него и напиши «Начать». Не блокируй этот диалог. Бот отправляет сообщения от сообщества только получателю из `.env`.
6. Перезапусти сайт. Открой настройки ВК и нажми **Отправить тестовое сообщение ВК**. Тест не требует брокерского токена и не включает уведомления. Между попытками — минимум минута, в том числе после неизвестного результата. «ВК принял сообщение» не гарантирует push: проверь сам диалог и настройки телефона.
7. Для рабочих сигналов в `.env` должен быть настроен **read-only INVEST_TOKEN**. Выбери акции, включи флажок ВК и сохрани.
8. В отдельном терминале из папки с `manage.py` запусти:

   ```powershell
   python manage.py watch_vk --seconds 28800
   ```

   Сайт должен работать одновременно. Команда собирает стакан и ленту по сохранённому списку ВК: до 50 акций в группе, смена группы через 15 минут, по умолчанию до 8 часов и 1 ГБ. После окончания запускай повторно. Перед запуском останови предыдущий `watch_vk`/`watch_telegram`, чтобы два сборщика не конкурировали за общий архив. Для обоих каналов используй одинаковые списки; разные списки требуют общего охвата сборщиком. Публичный адрес сервера, Callback и Long Poll для этого сценария не нужны.

## Какие события отправляются

### Одиночный радар и мульти-радар

На страницах **Стакан** (`/terminal/`) и **Радар заявок** (`/radar/`) есть отдельная галочка **Сообщения ВК**. Telegram остаётся независимым переключателем. При включении и выключении галочки ВК приходит подтверждение с названием радара. Повторные запросы состояния не отправляют это сообщение снова.

При включённом ВК поступают события существующего радара: крупные заявки, изменения объёма, исчезновение плотностей и предполагаемые пробои. Это наблюдения стакана, а не подтверждённые сделки других трейдеров и не готовая рекомендация покупать. Снятие заявки нельзя надёжно отличить от исполнения только по стакану.

Для этих двух страниц отдельный `watch_vk` не нужен: поток работает, пока открыта страница и запущен сервер с `INVEST_TOKEN`. Без открытой страницы автономная работа радара не гарантируется. Получатель берётся только из `.env`, подписок других пользователей нет. По умолчанию галочки выключены, после включения настройки сохраняются на сервере в `data/radar-vk.sqlite3`.

Отправка событий не задерживает биржевой поток: очередь ограничена 50 сообщениями, сообщения старше 20 секунд отбрасываются. Между событиями одной акции одного радара - минимум 10 секунд; одинаковое последнее событие повторно не отправляется, включая неизвестный результат доставки и перезапуск. Автоповтора сетевых ошибок нет. При всплеске событий часть уведомлений может быть пропущена. Статус приёма ВК виден рядом с галочкой.

### Основной анализ: кандидаты покупки

В разделе настроек основного анализа отправляются только кандидаты покупки LONG: все шесть основных условий совпали, нормальная торговая сессия, свежая оценка и согласованный биржевой стакан, без блокировок качества данных. Не пересылаются учебные данные, старые оценки, произвольные прогнозы нейросети, новости или сигналы шорта.

Сохраняются время снимка, ориентир входа, стоп и цель. Это сигнал экспериментальных правил, не гарантия доходности. Программа не выставляет биржевых заявок.

У ВК отдельные настройки и история (`data/vk.sqlite3`). Включение или перезапуск не сбрасывает защиту от повторов. Один сигнал на непрерывное совпадение условий; новый возможен после подтверждённого сброса и не раньше 30 минут. При неоднозначном ответе ВК автоматического повтора этого сигнала нет. Тестовая отправка не меняет торговую историю и всегда выполняется только после нажатия кнопки.

## Если сообщение не пришло

- **Бот не настроен:** проверь обе переменные и перезапуск сервера. Отображение настройки не проверяет действительность ключа.
- **ВК отклонил тест:** проверь право «Сообщения», числовой ID личной страницы, разрешение сообщений и отсутствие блокировки сообщества. Истёкший или отозванный ключ надо заменить локально и перезапустить сайт.
- **ВК (901):** подписка на группу не разрешает боту писать. Со своей личной страницы открой диалог именно со своим Vorby Pro, разреши сообщения и отправь «Начать». Диалог «ВКонтакте с авторами» к твоему боту не относится. После этого снова отправь тест или выключи и включи галочку радара.
- **ВК (902):** проверь ограничения приватности получателя и разрешение сообщений от твоей группы.
- **ВК (5), (27), (28):** проверь ключ сообщества в том `.env`, который читает запущенный сервер; после замены нужен перезапуск.
- **ВК (7), (15), (200):** проверь права ключа и включение сообщений сообщества. **ВК (113)** означает неверный ID получателя.
- **Приём не подтверждён:** сначала проверь диалог; автоматический повтор отключён для защиты от дублей.
- **Тест пришёл, рабочих сообщений нет:** проверь флажок, статус сборщика и активную группу акций. Без свежего подтверждения или совпадения всех шести условий сообщений не будет.

Основа API: [официальная схема VK, messages.send](https://github.com/VKCOM/vk-api-schema/blob/master/messages/methods.json), [инструкция команды VK](https://habr.com/ru/companies/vk/articles/570486/). Названия пунктов меню могут изменяться. Ключи, `.env` и реальные адресаты в браузере и ответах API сайта не раскрываются.
