## Величина результата внутри класса

Прежняя трёхклассовая модель и её калибровка загружаются из точного подписанного результата `risk-distribution-v1-20261103-210058-519766.json` и проверенных локальных весов. Они не переобучаются. Её вероятности и исходные денежные результаты должны воспроизводиться.

Для каждого класса чистой доходности (<−0,5%; от−0,5% до+0,5% включительно; >+0,5%) обучаются два новых прогноза величины результата: Ridge alpha100/SVD и HGB squared_error,150 итераций, шаг0,03, глубина3, максимум7 листьев, минимум40 строк в листе, L2=10, seed20261104, ранняя остановка выключена. Не менее40 известных train-строк на класс. Веса дат равны, StandardScaler только по train, признаки ограничены±8.

Цель — исходный net, ограниченный общими 2,5-м/97,5-м train-процентилями, делённый на известную прошлую волатильность. При прогнозе результат возвращается в исходные единицы и ограничивается минимумом/максимумом ограниченных train-ответов своего класса. **Тестовая прибыль не ограничивается.** Для каждой тестовой строки вычисляются все три результата; её настоящий будущий класс не выбирает прогноз.

Третий вариант — отдельные средние ограниченных train-ответов каждой акции/класса, с притяжением к прежнему глобальному среднему: вес локальной оценки n/(n+100). При отсутствии строк применяется глобальное среднее. Это регуляризация, n не объявляется числом независимых наблюдений. Новые неизвестные тикеры не поддерживаются.

## Другая оценка трёх вероятностей

Два HGB-классификатора учатся событиям net≥−0,5% и net>+0,5%. Отдельные sigmoid LogisticRegression калибруются на следующем году. HGB: прежние150 итераций/глубина3/7 листьев/минимум100/L2=10, seed20261104; Logistic:C1/lbfgs/max_iter1000/seed20261104. Если вероятность второго события выше первого, обе заменяются их средним. Затем P=(1−Pнеубытка, Pнеубытка−Pроста, Pроста). Частота такого пересечения публикуется. Коррекция использует только прогнозные числа, не фактический исход.

Шесть фиксированных оценок чистой доходности:

1. прежние вероятности × три Ridge-прогноза результата;
2. прежние вероятности × три HGB-прогноза результата;
3. прежние вероятности × средние для конкретной акции;
4. новые вероятности × прежние глобальные средние;
5. новые вероятности × средние для конкретной акции;
6. новые вероятности × три HGB-прогноза результата.

Новых обучений30:9 Ridge +9 HGB-регрессоров +6 бинарных HGB +6 Logistic-калибровок. Дополнительно используются6 прежних оценщиков, без обучения. Отдельные средние по акциям — статистические оценки, не дополнительные sklearn-fit.

## Восемнадцать правил и проверка

Каждая из шести оценок проверяется с тремя фиксированными входами: оценка net>0,10%; то же плюс вероятность класса убытка≤0,20; то же плюс вероятность убытка≤0,8 от частоты класса убытка в предыдущем году calibration. Это18 правил; все публикуются. Относительный порог вычисляется до test, не выбирается по доходности.

Прежние разделения train2018–2022/cal2023/test2024; train2018–2023/cal2024/test2025; train2018–2024/cal2025/test2026 до границы23 октября. Метки заканчиваются строго до конца раздела. Calibration обучает только две вероятностные калибровки и80%-е диапазоны абсолютной ошибки шести оценок. Параметры, пороги, веса смешивания и сдвиги прогнозов по test не подбираются.

Счёт100000 рублей отдельно на год, максимум25% на акцию, целые лоты, без шорта/плеча. Комиссия0,05% и проскальзывание0,05% каждого вида на каждой стороне. Стресс удваивает оба вида с теми же решениями. Неизвестные входы/выходы сохраняются и делают выбранный счёт неполным. Нет прибыли по удобной известной части и подстановки соседних цен.

Критерий прежний: в2025 и2026 минимум20 дат сигналов, положительные полные исходные счета и положительные результаты после пропуска1/3/5 лучших положительных дат при обоих уровнях расходов. Дополнительный флаг требует того же в2024. Лучшие даты выбираются задним числом только для проверки устойчивости, со всеми акциями даты и пересчётом оставшегося счёта. Все кварталы/пропуски кварталов сохраняются. Три контроля: прежние payoff_mean/payoff_safe_mean и медиана трёх net-моделей.

JSON `data/conditional-payoff-protocol-v1.json` содержит параметры/версии/SHA-256 до чтения примеров/обучения. Новые веса и результат сохраняются отдельно. Числа после загрузки проверяются с допуском1e−12, решения должны совпадать точно. Денежные сценарии пересчитываются независимым кодом. Никакого автоматического продвижения в рабочие рекомендации.
