# Исправления визуального аудита — 21 октября 2026

По просьбе пользователя устранены пять замечаний к контрастной теме.

1. **Обрезанная кнопка проверки истории на 1024 px.** Форма переведена на CSS Grid: четыре колонки на широком экране, две до 1200 px и одна на телефоне. Поля и кнопка ограничены своей колонкой. В проверке правый край кнопки — 954 px при ширине окна 1024, вместо прежних 1128 px.
2. **Нечитаемый мобильный график.** SVG больше не масштабируется из фиксированных 800×310. Область координат рассчитывается по реальным размерам контейнера и обновляется при изменении размеров. На телефоне высота 280 px, подписи осей — 11 px, три подписи времени вместо четырёх. При ширине SVG 313,6 px эффективный размер текста — 10,99 px вместо прежних 3,92 px. Все исходные свечи, индикаторы и условия разметки сохранены.
3. **Разрыв надписей радара.** Добавлены явные классы панели и группы контролов. Группа переносится целыми элементами, подписи кнопки списка и переключателя не разрываются, переключатель не сжимается. На 1024 px подпись «Мульти-бот» занимает одну строку (23 px вместо 46).
4. **Лишние десятичные знаки в калькуляторе.** Для обычных цен от 1 используются копейки: `282.628368451` → `282.63`. Для цен меньше рубля сохраняется до восьми знаков без лишних нулей; очень малая положительная цена не превращается в ноль. Это форматирование редактируемых ориентиров, **не проверка биржевого шага цены**. Калькулятор отправляет именно значения, видимые в полях, а не скрытую исходную точность; перед расчётом явно предложено проверить цены и шаг инструмента. Серверный сигнал и исторические расчёты не округлялись.
5. **Пустая диаграмма портфеля.** Добавлены состояния loading/empty/unavailable/ready. При отсутствии данных или библиотеки графика, пустом портфеле и ошибке API — компактный текст вместо пустого canvas на 260 px. В браузере высота компактной карточки — около 67 px. Ошибка API показывается над карточками, неизвестные суммы остаются прочерками. При успешном пустом ответе реальные нулевые суммы допустимы. Если сломалась только библиотека диаграммы, таблица доступного портфеля не объявляется недоступной. Полная высота диаграммы возвращается только при наличии данных и работающего рендера.
